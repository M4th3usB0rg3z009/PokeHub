# PokeHub

Uma Pokédex desenvolvida com React, Node.js e TypeScript, integrada à PokéAPI e Inteligência Artificial para fornecer informações detalhadas sobre Pokémon, além de responder perguntas sobre builds, natures, habilidades, estratégias e outros aspectos do jogo.

## Objetivo

Este projeto foi criado com o objetivo de aprimorar meus conhecimentos em:

- Consumo de APIs REST
- Integração com Inteligência Artificial
- Desenvolvimento Full Stack
- React
- Node.js
- TypeScript

## Tecnologias

- React
- TypeScript
- Node.js
- Express
- PokéAPI
- OpenAI API
