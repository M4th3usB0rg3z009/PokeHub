# ⚡ PokéHub

O **PokéHub** é uma plataforma web desenvolvida para centralizar informações sobre Pokémon em um único lugar. Integrando a **PokéAPI** com Inteligência Artificial, o projeto permite pesquisar Pokémon e obter informações detalhadas, além de receber recomendações de builds, natures, itens, golpes e estratégias de batalha.

## 📖 Sobre o projeto

O objetivo deste projeto é aprofundar meus conhecimentos em desenvolvimento **Full Stack**, explorando a integração entre APIs externas e modelos de Inteligência Artificial em uma plataforma web.

Além de exibir dados oficiais da PokéAPI, o PokéHub utiliza IA para responder perguntas sobre Pokémon, explicar mecânicas do jogo e fornecer recomendações estratégicas de forma contextualizada.

## 🎯 Objetivos

Durante o desenvolvimento deste projeto, busco praticar:

- Desenvolvimento Full Stack
- Consumo de APIs REST
- Integração com Inteligência Artificial
- React com TypeScript
- Node.js e Express
- Comunicação entre Frontend e Backend
- Arquitetura e organização de projetos
- Boas práticas de desenvolvimento

## ✨ Funcionalidades

- 🔍 Pesquisa de Pokémon por nome ou número
- 📖 Informações detalhadas sobre cada Pokémon
- 📊 Estatísticas, habilidades, tipos e evoluções
- ⚔️ Fraquezas e resistências
- 🤖 Assistente com Inteligência Artificial
- 🧠 Recomendações de builds, natures, itens e golpes
- 💬 Respostas para dúvidas sobre estratégias e mecânicas do jogo
